## Открытая работа

### 1. Живая приёмка

Автоматические гейты (`pnpm run check`) зелёные, хостовая половина Remote проверена живыми
запросами. Не закрыто: установка в живой web-профиль rc.2, жёсткое обновление страницы и проход
чеклиста ниже в браузере (CDP/вручную). Парный тест-стенд платформы
`@deepseek-ai/dsh-client-test-runtime` для этого не годится: опубликованный `lib/` импортирует
неопубликованные `src/`-пути и падает на `ERR_MODULE_NOT_FOUND`, поэтому клиентский ярус тестов —
локальный jsdom-стенд (`test/client/`).

Чеклист:

1. профиль не выбран нигде → промпт не изменён (сравнить с сессией без бандла);
2. `default` задан, `last` пуст → применяется `default`;
3. явный выбор → применяется он и запоминается; новая сессия в том же воркспейсе — он же;
4. другая поверхность (не web) в том же воркспейсе → применяется `last`;
5. `scope: main-only` не протекает в субагента; `inherit` протекает; fork наследует всё;
6. порядок секций соответствует outline; одинаковые order допустимы, ничего не смещается; при
   равенстве с присутствующей built-in своя секция вставляется перед ней;
7. правки конфига и удаление профиля не влияют на идущую сессию; resume воспроизводит промпт;
8. сессия в mode `minimal` → предупреждение о complete-mode видно в чипе и в редакторе;
9. чип: три состояния (нет ключа → default, `""` → «нет», id → профиль), выбор без воркспейса
   блокируется с объяснением;
10. i18n: en/ru/zh без непереведённых ключей;
11. drag&drop и стрелки на ручке переупорядочивают состав профиля; Esc/back не выбрасывают из
    формы с несохранённой правкой;
12. пути ошибок: недоступный Remote, конфликт ревизии (re-apply + сообщение), пустой title.
